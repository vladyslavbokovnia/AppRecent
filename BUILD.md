# Сборка

Исходный репозиторий был пустым, поэтому `AppRecent-base.apk` — предоставленный бинарный baseline. GitHub Actions проверяет изменения восстановленной apktool-основы и публикует baseline APK как артефакт. Для полноценной пересборки модифицированного APK нужен оригинальный Android-проект или исходники: бинарная декомпиляция не восстанавливает private framework resources Android 34.
