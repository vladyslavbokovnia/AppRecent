# Обновление AppRecent 2.1

Начиная с версии 2.1 APK подписывается постоянным ключом AppRecent и собирается как release. Последующие версии с тем же applicationId и ключом устанавливаются поверх этой версии, поэтому Accessibility Service и остальные разрешения не нужно выдавать заново.

APK до версии 2.1 были временными debug-сборками с другой подписью. Android не позволяет обновить их APK с другой подписью. Поэтому переход на 2.1 может потребовать один раз удалить старую debug-версию и включить разрешения для 2.1. После этого обновления из Actions будут ставиться поверх.
