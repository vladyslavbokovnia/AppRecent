# AppRecent — Kotlin / Jetpack Compose

Полный исходный Android-проект создан с нуля. Декомпилированный APK больше не используется как основа.

## Реализовано

- список всех приложений с launcher-иконкой, включая само AppRecent;
- режим **Недавние** через `UsageStatsManager`: приложение после запуска становится последним;
- режим сортировки по дате установки;
- режим **Все видимые на экране** на плавном `LazyRow` и режим **Постраничный**;
- плавная анимация перехода к последнему приложению через `animateScrollToItem`;
- long-press меню со стрелкой «предыдущая позиция», скрытием и настройками приложения;
- ручной порядок хранится отдельно, но после запуска приложения его ручное смещение сбрасывается, поэтому при следующем запуске оно снова становится последним;
- пользовательские и системные иконки отображаются через `FIT_CENTER`, без обрезки;
- экран настроек всегда использует тёмную Material 3 тему;
- overlay работает через Accessibility Service, а проект собирается GitHub Actions.

## Сборка

```bash
gradle :app:assembleDebug
gradle :app:testDebugUnitTest
```

На устройстве нужно выдать разрешения overlay, Usage Access и Accessibility Service на экране настроек.
