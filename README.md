# AppRecent

В репозитории восстановлена сборочная основа из `AppRecent.apk`, поскольку исходный GitHub-репозиторий был пустым. Сборка выполняется через **apktool** и публикуется как артефакт GitHub Actions.

## Изменения

- собственное приложение больше не исключается из списка запускаемых приложений;
- порядок «Недавние» сохраняет последнее использование, поэтому активное приложение появляется последним после обновления;
- пользовательские картинки иконок отображаются целиком (`fitCenter`), без `centerCrop`;
- в меню добавлена стрелка «предыдущая позиция» как UI-контрол для ручного смещения;
- экран настроек сохранён в постоянной тёмной теме;
- обновление списка использует плавную прокрутку RecyclerView.

> Важно: оригинальные исходники в созданном репозитории отсутствовали. Для полного развития функции ручного смещения в следующей итерации нужен исходный проект либо подтверждение поведения кнопки (перемещать на одну позицию или в начало).
