# Логика отображения

Список формируется из всех launchable-приложений, включая `com.statusoverlay.app`. Скрытые пакеты фильтруются отдельно. В режиме недавних `UsageStatsManager` используется только для времени сортировки; приложение, запущенное после открытия оверлея, получает актуальное время использования и оказывается в конце отображаемого списка. При нажатии запуска обновление выполняется после запуска, а переход к последней позиции происходит через `smoothScrollToPosition`.

Для пользовательских изображений используется `fitCenter`: картинка сохраняет пропорции и не подрезается по краям.
